# 고객 진행 보고 템플릿

## 자리표시자와 예시

- `[CUSTOMER_NAME]`
  - 예시: `가나다상사`
- `[REQUEST_ID]`
  - 예시: `REQ-1042`
- `[REPORTING_PERIOD]`
  - 예시: `2026-09-01 ~ 2026-09-07`
- `[COMPLETED_ITEMS]`
  - 예시: `주문 목록 엑셀 다운로드 구현, 권한 테스트 6건 통과`
- `[CURRENT_ITEMS]`
  - 예시: `고객 검수용 데이터 준비`
- `[BLOCKERS]`
  - 예시: `없음`
- `[CUSTOMER_ACTION]`
  - 예시: `9월 9일까지 엑셀 열 순서를 확인해 주세요.`
- `[NEXT_REPORT_DATE]`
  - 예시: `2026-09-14`

## 템플릿

제목: `[REQUEST_ID]` 진행 보고 — `[REPORTING_PERIOD]`

`[CUSTOMER_NAME]` 담당자님,

이번 보고 기간에 완료한 내용은 다음과 같습니다.

- `[COMPLETED_ITEMS]`

현재 진행 중인 내용:

- `[CURRENT_ITEMS]`

진행을 막는 사항:

- `[BLOCKERS]`

고객 확인이 필요한 내용:

- `[CUSTOMER_ACTION]`

다음 진행 보고 예정일은 `[NEXT_REPORT_DATE]`입니다. 일정이나 범위에 변동이 확인되면 예정일을 기다리지 않고 먼저 공유드리겠습니다.

## 사용할 때

- 작업이 7일을 넘겨 주간 진행 보고를 보낼 때 사용한다.
- 일정, 범위, 장애 또는 고객 확인 사항이 바뀌어 중간 보고가 필요할 때 사용한다.

## 사용하지 않을 때

- 견적서, 계약서, 장애 최초 통보 또는 최종 완료 보고를 대신하지 않는다.
- 확인하지 않은 완료율, 복구시각 또는 납품일을 채워 넣지 않는다.
