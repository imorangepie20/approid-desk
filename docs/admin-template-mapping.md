# Approid Desk 관리자 템플릿 적용 기준

## 목적

`admin-template-source`의 화면 구조와 시각 기준을 Approid Desk의 Blade와 Livewire 화면에 일관되게 적용한다. React 라우터와 컴포넌트 코드는 운영 애플리케이션에 포함하지 않는다.

## 원본 확인 결과

- 원본 이름은 `hud-admin-template`이며 React 18, Vite, Tailwind CSS 3과 Lucide React로 작성되어 있다.
- 저장소의 운영 기술은 Blade, Livewire, Tailwind CSS와 Flux UI이므로 React 런타임을 추가하지 않는다.
- 원본의 `package.json`은 `private: true`이지만 별도 `LICENSE`, `NOTICE`, `README` 파일은 없다.
- 이 원본은 프로젝트 소유자가 제공하고 적용을 지시한 내부 자료로만 사용한다. 외부 배포나 재판매 자료에 원본 소스와 자산을 포함하려면 별도 사용권 확인이 필요하다.
- 이미지나 글꼴 파일을 그대로 복사하기보다 레이아웃, 색상 토큰과 상태 표현을 현재 Tailwind 구성으로 다시 작성한다.

## 유지할 화면 구조

| 원본 구성 | Approid Desk 적용 | 구현 위치 |
| --- | --- | --- |
| `MainLayout` | 고정 사이드바, 상단 헤더, 본문 영역 | `resources/views/layouts/app.blade.php`와 하위 레이아웃 |
| `Sidebar` | 역할별 업무 메뉴와 접기 기능 | `resources/views/layouts/app/sidebar.blade.php` |
| `Header` | 메뉴 토글, 알림, 사용자 메뉴, 테마 전환 | `resources/views/layouts/app/header.blade.php` |
| `Dashboard` | 시간 현황 카드, 승인 대기, 검수 대기, 진행 작업 | 운영자와 고객 대시보드 Livewire 화면 |
| `HudCard`와 `StatCard` | 공통 카드와 지표 카드 | Blade 컴포넌트 |
| `TableElements` | 요청, 견적, 작업시간, 월 사용내역 목록 | 공통 표와 모바일 카드 목록 컴포넌트 |
| `FormElements` | 요청, 견적, 작업시간 입력 | Flux 입력 요소를 감싼 공통 폼 구성 |
| `ScrumBoard` | 요청 상태 흐름의 참고 화면 | 후속 범위로 두고 첫 운영 버전은 목록과 상세 중심으로 구현 |
| `Calendar` | 예정일과 납기일 표시 참고 | 후속 범위로 두고 첫 운영 버전은 날짜 필터로 구현 |
| `Pricing` | 내부 가격 기준 화면 참고 | 운영자 가격 기준 관리 화면 |

### 고객사 관리자

## 화면별 적용 기준

### 대시보드

- 상단에 페이지 제목과 기준 월을 표시한다.
- 첫 행에는 제공시간, 실사용시간, 예약시간, 사용 가능시간 카드를 같은 순서로 배치한다.
- 운영자 화면은 고객사별 잔여시간, 승인 대기, 검수 대기와 진행 작업을 추가로 표시한다.
- 숫자는 카드에서 크게 표시하되 단위가 분인지 시간인지 함께 표시한다.
- 상태 색상만으로 의미를 전달하지 않고 상태 이름을 함께 표시한다.

### 목록

- 데스크톱은 표, 모바일은 핵심 필드를 묶은 카드 목록으로 표시한다.
- 필터는 목록 위에 두고 현재 적용된 필터를 지우는 동작을 제공한다.
- 행 전체를 클릭할 수 있게 만들더라도 제목 링크와 주요 작업 버튼에는 명확한 이름을 둔다.
- 빈 목록, 로딩, 오류와 권한 없음 상태를 각각 표시한다.

### 상세

- 제목, 상태, 우선순위, 고객사와 담당자를 첫 화면에서 확인할 수 있게 한다.
- 요구사항, 견적 버전, 댓글, 첨부파일, 작업시간과 변경 이력은 구획을 나누어 표시한다.
- 상태 변경과 승인 작업은 일반 링크와 구분되는 버튼으로 표시하고 확인 절차를 둔다.
- 변경 이력은 최신순으로 보되 이전 값, 새 값, 처리자, 시각과 사유를 확인할 수 있게 한다.

### 입력 화면

- 모든 입력에는 화면에 보이는 라벨과 오류 문구를 둔다.
- 필수 입력과 선택 입력을 구분한다.
- 저장 중에는 중복 제출을 막고 성공 또는 실패 결과를 표시한다.
- 파일 입력에는 허용 형식, 최대 용량과 개수 제한을 업로드 전에 표시한다.

## 시각 토큰

원본의 HUD 색상 체계는 유지하되 업무 화면의 가독성을 우선한다.

| 용도 | 밝은 화면 | 어두운 화면 | 사용 기준 |
| --- | --- | --- | --- |
| 기본 배경 | `#f0f2f5` | `#0E1726` | 전체 화면 배경 |
| 보조 배경 | `#ffffff` | `#141B2D` | 사이드바와 헤더 |
| 주 강조색 | `#0891b2` | `#00FFCC` | 선택 상태와 기본 작업 |
| 성공 | `#059669` | `#10B981` | 완료와 정상 상태 |
| 경고 | `#d97706` | `#FFA500` | 승인 대기와 주의 상태 |
| 위험 | `#dc2626` | `#EF4444` | 취소, 삭제와 오류 |
| 기본 글자 | `#111827` | `#FFFFFF` | 제목과 본문 |
| 보조 글자 | `#4b5563` | `#A0AEC0` | 설명과 부가 정보 |

- 본문 글꼴은 현재 Starter Kit의 Instrument Sans를 유지한다. 템플릿의 Inter와 Roboto를 새로 추가하지 않는다.
- 코드, 식별자와 시간 원장의 분 값에만 고정폭 글꼴을 제한적으로 사용한다.
- 카드의 모서리 장식과 빛나는 효과는 대시보드 지표에만 사용한다. 입력 화면과 긴 표에는 사용하지 않는다.
- 애니메이션은 짧은 상태 전환에만 사용하고 `prefers-reduced-motion` 설정을 존중한다.

## 제외할 원본 기능

- 이메일 받은편지함과 작성 화면
- AI 채팅과 이미지 생성
- POS 전체 화면
- 제품과 갤러리
- Chart.js 예제 화면
- Bootstrap 예제 화면
- React Router와 React 상태 관리 코드

위 기능은 Approid Desk의 첫 운영 범위와 무관하므로 복사하지 않는다.

## 완료 확인

- 원본 화면과 공통 컴포넌트의 적용 여부를 목록화했다.
- 역할별 사이드바 메뉴를 정의했다.
- 밝은 화면과 어두운 화면의 색상 기준을 정했다.
- 목록, 상세, 입력과 대시보드의 공통 동작을 정했다.
- 현재 기술 구성에서 제외할 React 기능을 분리했다.
- 원본에 별도 라이선스 파일이 없음을 기록하고 외부 재배포 제한을 명시했다.
